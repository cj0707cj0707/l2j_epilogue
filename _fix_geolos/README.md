## Задача

Любые персонажи (игроки и боты) должны уметь стрелять/кастовать и использовать **любые скиллы**
(включая чардж-рывки) по цели, которая находится за стеной/преградой.

## Причина (почему сейчас нельзя)

1. **Геодата на сервере не установлена** (`game\data\geodata` пуст — только Readme). При старте
   `GeoEngine` загружает 0 регионов, все 1024 региона мира — `NullRegion`. Поэтому **рельеф, стены,
   дома и земля никогда не блокируют** ни видимость, ни проверку пути — тут блокировать нечему.
2. **Но ядро поверх геодаты проверяет ещё два вида преград** — в
   `GeoEngine.canSeeTarget(...)` и `GeoEngine.canMoveToTarget(...)`
   (`org/l2jmobius/gameserver/geoengine/GeoEngine.java`):
   - `DoorData.checkIfDoorsBetween(...)` — **закрытые двери** (двери мира из `Doors.xml` + двери инстансов);
   - `FenceData.checkIfFenceBetween(...)` — **заборы** (`FenceData.xml`, ставятся и админ-командой).
   Если луч «стрелок → цель» пересекает закрытую дверь или забор — проверки возвращают `false`.
   Это и есть эффект «за стеной/преградой»: закрытая дверь — та же стена.

## Фикс (один файл, два метода одного класса)

`GeoEngine.java` (`org.l2jmobius.gameserver.geoengine.GeoEngine`):

1. `canSeeTarget(int x, int y, int z, int targetX, int targetY, int targetZ, int instanceId)`
   → всегда `true`: проверки `DoorData`/`FenceData` убраны. Все оверлоны и все потребители
   (таблица выше) проходят через этот метод — атака/каст/AoE/урон/авто-движки больше не
   блокируются преградами.
2. `canMoveToTarget(int fromX, fromY, int fromZ, int toX, int toY, int toZ, int instanceId)`
   → всегда `true` (оба оверлона делегируют к нему). Открывает чардж-скиллы на цель за
   закрытой дверью и подход ботов/саммонов/NPC.

**Не тронуто (намеренно):**
- `getValidLocation(...)` — подрезка маршрута у закрытых дверей осталась: **обычная ходьба**
  по-прежнему останавливается у двери, сквозь неё не проходят (изменится только «упор в дверь
  вплотную» вместо остановки за ~10 ярдов);
- гео-рейкаст по ячейкам внутри `canSeeTarget`/`canMoveToTarget`-цепочек (без геодаты он и так
  всегда успешен), движение/пути (`PathFinding` отключён — геодаты нет), PvP/peace-правила,
  олимпиада, статы, рейты.

## Что проверить в игре (для администратора)

- Игрок за закрытой дверью/забором: автоатака и любой скилл (дамаг, дебаф, AoE) по цели за преградой;
  сообщение «You cannot see your target» больше не появляется.
- Чардж-скиллы (Rush Impact и т.п.) на цель за закрытой дверью — каст проходит.
- Боты (FakePlayersAI) воюют с целью за преградой, не «висят» и не сбрасывают таргет.
- Урон дальними скиллами по игрокам за дверью больше не «молчит».
- Ходьба: персонаж по-прежнему **не проходит** сквозь закрытую дверь (только атаки/касты).

## Замечания

- Если когда-нибудь установите геодату: этот фикс продолжит пропускать атаки/касты сквозь
  рельеф и стены (LOS всегда истинен). Откат вернёт штатное поведение.
- Мобы/охрана тоже «видят» цель за закрытой дверью и подойдут к двери вплотную (без геодаты
  они и так ходят сквозь стены — меняется только момент остановки и агро/каст сквозь двери).
- Сервер после установки агентом **не запускался** — запуск и игровая проверка за администратором.
