# 77. Мили-преследование не ограничено кругом кайта

База: `2167252cd9088137965d5739cafe029b08eb5616` (76). Резервная ветка: `backup/before-melee-pursuit-outside-kite-circle-2026-10-20`.

## Поведение

- Мили-бот, сближающийся для атаки, больше не упирается в круг кайта450/служебный native предел460. Преследование, перехват, обычный заход сбоку/сзади и обход после Bluff могут выходить за этот круг.
- Это относится к мили-ролям текущего пула: Duelist88, Phoenix Knight90, Hell Knight91, Adventurer93, Wind Rider101, Shillien Templar106, Ghost Hunter108, Titan113, Grand Khavatari114, Doombringer131. Роль определяется родным пресетом класса, а не временно надетым оружием.
- Сам кайт не расширен: круговые точки, отход от неуязвимой/защищённой цели, recovery и отступление для Rush используют прежние планировщики и450. Возвращение из внешней точки происходит обычным движением, не переносом на границу. Промежуточная точка возврата может ещё быть снаружи круга.
- Сохранён прежний внешний защитный диапазон преследования:2000 от центра олимпийской арены,1000 на тренировочной. Это не разрешение проходить через стены: проверки геодаты, инстанса, действующей пары/матча, управления движением и кастов не обходятся.
- У магов/лучников/арбалетчика в бот–бот остаётся прежняя глобальная native граница460. Бой с человеком не получает нового ограничения460.

## Причина и исправление

`ArenaCombatRules.update` раньше привязывал **обоих** участников бот–бот к `ArenaBoundaryGuard`: ядро резало любые координаты/перемещения по460, не отличая атаку от кайта. В результате даже корректная точка преследования за кругом становилась недостижимой.

Теперь адаптер независимо проверяет **собственный** класс каждого участника. У мили очищается глобальная радиальная привязка; остальным она назначается как прежде. Это работает и тогда, когда первым отрабатывает драйвер противника-мага. Мили за460 также больше не нормализуется на460 при входе в тактику.

Важно: это именно снятие **универсального** ограничения450/460 у мили, а не новая native проверка «намерения погони» каждого движения. Ограничения добровольного кайта остаются в его планировщиках; native радиальный clamp больше не является общей стеной для мили, в том числе при иных штатных перемещениях. Защита реальной арены/геодата остаются штатными. Исходник helper, установщики core-патчей, JAR, скорость, телепорты и система столкновений не менялись. При отсутствии обязательного core helper бой бот–бот по-прежнему блокируется.

`BluffRear` отдельно ограничивал **все** точки атакующего обхода радиусом449. Он использует внешний диапазон атаки2000/1000 вместо зоны кайта. По-прежнему проверяется весь путь и каждый геосегмент; обычные промежуточные шаги, задний сектор и дистанция до40 для ударов сохранены. Во время собственного действующего стана Bluff — только умения с реальной спины, без автоатаки. Неподвижность, запреты действий и отсутствие достижимого пути не превращаются в телепорт.

## Проверка

Команды:

```bash
python tests/fakeplayersai/passive_barrier_bluff_tests.py
python tests/fakeplayersai/arena_orbit_trance_mana_tests.py
```

Результат: **PASS всех13 наборов**, компиляция custom/effect scripts успешна. Новый набор77: **29777** проверок; расширенный Clarity/Bluff-набор: **13836**. Отдельный прогон ядра также PASS, включая fail-closed без helper и неизменность исходного JAR.

Тесты используют временную копию JAR с настоящими native обёртками и штатными Skill/Formulas. Проверяются обе очередности драйверов, координаты450/460/461/600/900 и1500 для ranked-мили; отдельный тест сверяет2000 с константой существующего драйвера. Полный тест обхода использует native PlayerAI admission, но фактическое движение мира записывает оснастка и затем моделирует прибытие. Это **не** живой матч, не проверка конкретных стен арены в работающем мире и не тест с подключённым клиентом.

Самостоятельный тест ядра дополнительно проверяет порядок native обёрток, резервирование/idempotence установщиков, отказ при неизвестном/повреждённом ядре, блокировку без helper и неизменность исходного `libs/GameServer.jar`.

Шансы сна20%/Bluff40%, reuse Bluff12с, Cardinal Prominence строгоHP>90% с интервалом10с, его правила сна/щитов, бижутерия и длительность боя210с сохранены.

## Установка

Изменения внесены в GitHub, а не в установленный `C:\EpilogueServer`. Обновить вместе три production-файла из таблицы в `game\data\scripts\custom\fakeplayersai\` и полностью перезапустить GameServer через существующий поддерживаемый launcher. Новый core-патч/JAR не нужен; прежние обязательные core-патчи должны оставаться установленными. БД и пользовательские overrides не менять.
