# 16. Giran: Adena Giver — 100 миллионов адены за нажатие

## Изменение от 15.10.2026

На центральную площадь Гирана добавлен четвёртый кастомный сервисный NPC — **Adena Giver**, титул **100 Million Adena**. Стоит в одном ряду с Blacksmith Aug, Enchanter и Skill Enchanter, на 64 единицы по X дальше Skill Enchanter.

- **npcId:** `1007000`; **displayId:** `31960` (тот же внешний вид, что у соседних сервисных NPC).
- **Позиция:** `83185, 148613, -3455`; **heading:** `16384`; **respawnDelay:** `60` секунд.
- **Тип:** `Folk`, неподвижный, неатакуемый; имя и титул передаются сервером.
- При разговоре открывает community board (alt+b) с единственной кнопкой **Get 100,000,000 Adena**. Само открытие окна валюту не выдаёт.
- Одно нажатие кнопки добавляет **ровно 100 000 000 адены** (предмет `57`) к текущему балансу, а не устанавливает баланс в 100 миллионов.
- Бесплатно, доступно обычным игрокам. Выдачу можно повторять без кулдауна, суточного лимита или привязки к аккаунту.

## Механика и проверки

- `NPC_ID = 1007000`, `ADENA_AMOUNT = 100_000_000L` — константы в скрипте. Для изменения суммы нужно согласованно поменять константу, текст окна/кнопки и сообщение об отказе; для смены npcId — константу, шаблон и спавн.
- Кнопка вызывает `bypass -h Script AdenaGiver give`. Скрипт принимает только точное событие `give`; сумма от клиента не принимается.
- `onFirstTalk` открывает окно; `onEvent` обрабатывает выдачу. HTML отправляется через `HtmlUtil.sendCBHtml(player, MENU, npc.getObjectId())`: objectId NPC сохраняет origin страницы для штатной проверки bypass.
- Дополнительно проверяются ненулевые player/NPC, правильный npcId и `npc.canInteract(player)` (штатная проверка возможности взаимодействия, включая расстояние). Чужой NPC или недоступный NPC не выдаёт валюту.
- Выдача запрещена мёртвому игроку, в бою, при касте/атаке, торговле, обработке запроса или рыбалке.
- Если `player.getAdena() > PlayerConfig.MAX_ADENA - ADENA_AMOUNT`, вся выдача отклоняется. При остатке ровно 100 миллионов начисление разрешено. Это не даёт штатному API обрезать сумму у лимита.
- Начисление: `player.addAdena(ItemProcessType.QUEST, ADENA_AMOUNT, npc, true)` — штатный валютный API, без рейтов дропа/квестовых наград. Обновление инвентаря, хранение валюты и системное сообщение выполняет ядро. Прямых SQL-запросов скрипт не делает.
- После обработки кнопки окно остаётся доступным для следующего нажатия. При отказе выводится сообщение без изменения баланса.

**Важно:** это намеренно неограниченный источник бесплатной адены. Не включать на сервере с обычной игровой экономикой без осознанного решения владельца.

## Установка на работающий сервер

Изменение в GitHub само по себе не обновляет запущенный сервер.

1. Остановить GameServer штатным способом.
2. Перенести три новых файла из таблицы выше в соответствующие папки `C:\EpilogueServer\game\data\` (либо обновить локальную копию репозитория).
3. Запустить GameServer. XML загрузится с датапаком, Java-скрипт скомпилируется штатной системой скриптов. Проверить консоль и `game/log/error0.log` на ошибки загрузки AdenaGiver.
4. В игре прийти к `83185,148613,-3455`, рядом со Skill Enchanter. Поговорить с Adena Giver; проверить кнопку обычным персонажем.
5. Записать баланс, нажать кнопку один раз: прибавка должна быть 100 000 000. Повторить: ещё 100 000 000. Перезайти и проверить сохранение баланса.
6. Проверить отказ вдали от NPC и у лимита адены; убедиться, что три прежних NPC работают как раньше.
