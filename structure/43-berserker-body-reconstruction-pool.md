# 43. Berserker: Body Reconstruction отсутствовал в пуле лечения

> **Уточнение48:** правило «во время STUN на противнике — только Rush» теперь имеет одно срочное исключение: магический self-cast Soul Cleanse1510 при ROOT/PhysicalMute на самом берсеркере. Уже выполняемый каст не прерывается, остальные heal/filler-приоритеты не меняются. См. [48](48-berserker-emergency-soul-cleanse.md).


База: `7a93669bdf6ce7952795b4714da1fd858c8d90f4`.
Резерв: `backup/before-berserker-body-reconstruction-pool-2026-10-17`.

## Причина и точечное исправление

В пресете131 по умолчанию есть Body Reconstruction833, но в реально сохранённом `game/config/Custom/FakePlayersAIOverrides.ini` стоят:

```ini
buffs.131=500,499,917,483
rotation.131=793,485,501,794,497,526
```

833 отсутствует в обоих списках. Общий `BotTactics.act` собирал кандидатов из эффективной ротации, buffs, танковых защит и CP-пула Dominator. Для131 обязательного добавления изученного833 не было. Порог HP≤40% и высокий приоритет восстановления существовали, но навык не доходил до проверки этого порога/выбора. Исправление42 затрагивало отсутствие CP-умений115, а не этот отдельный пробел131.

В `BotTactics.java` добавлено обязательное включение **уже изученного**833 для класса131 в локальный список кандидатов. Это одна дополнительная операция, аналогичная существующему добавлению Sacrifice69 для90. Сохранённые настройки не переписываются, другие навыки/классы не меняются, отсутствующий у персонажа833 не выдаётся.

## Поведение и сохранённые ограничения

- В тренировке и через олимпийский `tickDefense` навык может выбираться при **HP≤40%**, с существующим приоритетом300 перед обычными атаками.
- Под неуязвимостью самолечение по-прежнему запрещено при выборе, перед native cast и при выполнении эффекта.
- Прежнее явное правило42 **«пока противник в STUN — только Rush Impact»** не отменено: во время этой фазы833 не подменяет Rush. После окончания стана снова доступен обычный отхил.
- Native833: SELF,94MP, cast1500мс, reuse900000мс (**15 минут**), HealPercent100. НехваткаMP, реальный откат, silence/CC и другие native условия остаются блокировками. Уже начатый каст не прерывается ради отхила.
- XML, общие шаблоны навыков, ядро/JAR, БД и настройки override не редактировались.

## Проверки

`python3 tests/fakeplayersai/berserker_body_reconstruction_tests.py` —94 проверки:

- загружен настоящий persisted override; точные statements построения skill-pool берутся из production `act`, не дублируются вручную;
- старое построение pool из7a93669 воспроизводит отсутствие833 при изученном навыке; текущее включает его в обоих режимах;
- неизвестный833 не добавляется, другим классам новый обязательный833 не навязывается;
- проверены реальные Skill/Player, HP39.99/40/40.001%, event guard, invulnerability, native MP93/94 и реальный getter отката;
- выполнен настоящий `HealPercent.onStart`: с4000HP до10000HP; под неуязвимостью остаётся4000. Только UI/regen-status заменён headless seam, без игрового сервера/DB/таймеров;
- source-wiring сохраняет native eligibility и приоритет Rush-only. Все custom-скрипты компилируются против поставленных JAR.

Связанные регрессии восстановления40/70%, физического low-MP fallback, CP/melee/Rush42 и многоциклового ranked Rush также выполнены. Это автономные проверки, **не подтверждение живого матча**.
