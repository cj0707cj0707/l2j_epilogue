## Конфликт 4 [RESOLVED] — Dominator rooted + sleeping tank: граничный случай

**Решение пользователя:** «Доминатор должен пытаться усыпить танка снова, если рут всё ещё действует.»

**Реализация (документационная):**
- В callout документа79 добавлено: «Если Dominator заруteован в момент пробуждения танка — применяется правило81: стационарная ротация с места, включая немедленную попытку1097 с текущей позиции (без отхода); отход до300 возобновляется только после снятия рута.»
- В п.4 документа80 (после пробуждения цели) аналогичное уточнение для рутованного Dominator.
- **Требуется кодовое изменение:** в `BotTactics.java` в блоке выхода из `dominatorTankSleepHold` добавить проверку `isRooted()` и направить в стационарную ротацию (правило81) вместо попытки отхода.

## Конфликт 5 [RESOLVED] — Cancel Archmage/Mystic Muse: механика разъяснена

**Решение пользователя:** «Cancel — это скилл, который снимает положительные баффы с противника, а не дбаффы с себя. Он должен применяться на противника, чтобы лишить его баффов. Cancel не может снять Trance.»

**Реализация (документационная):**
- В документ80 раздел2 добавлен явный параграф: **«Cancel1056 применяется на противника с целью снятия его положительных баффов (slot=buff). Trance1394 является дебаффом (CC), наложенным Cardinal на противника — не его баффом. Cancel не может снять Trance. Цикл "Cancel снял Trance → Cardinal перекладывает → Cancel снова" невозможен по механике.»**
- Конфликт5 в исходном отчёте был основан на неверном понимании механики Cancel; реального конфликта нет.

## Конфликт 7 [RESOLVED] — Порядок Soul Cleanse vs. Escape Shackle при руте

**Решение пользователя:** «Soul Cleanse и Escape Shackle должны быть применены немедленно при руте.»

**Реализация (документационная):**
- Оба хука применяются **немедленно** при обнаружении `isRooted()`, без ожидания очереди ротации.
- Зафиксированный порядок в коде: **(1) escapeShackle453** (Dagger93/101/108) → **(2) soulCleanse1510** (Berserker131).
- Классы взаимоисключающие — для каждого бота срабатывает ровно один хук. Порядок важен для безопасности при будущих расширениях.
- Добавлены callout-ы в [48](48-berserker-emergency-soul-cleanse.md) и [49](49-dagger-escape-shackle-root-only.md).
- Создан новый документ [83-mandatory-hooks-order.md](83-mandatory-hooks-order.md) с полной таблицей хуков.
- **Требуется кодовое изменение:** убедиться, что в `BotTactics.act` escapeShackle стоит до soulCleanse и оба вызываются **до** reaction-таймера и normal-rotation.
