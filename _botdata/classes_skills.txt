## MISC
- experience.xml: levels 1..87 defined; level 85 exists (tolevel 19,827,360,000); server max level is 87.
- Skill trees: game\data\stats\players\skillTrees\{StartingClass,1stClass,2ndClass,3rdClass}\*.xml (11/20/36/36 files). The classId inside <skillTree classId="N"> is authoritative; do NOT trust file names (case differs from templates, e.g. skillTrees\3rdClass\Swordmuse.xml vs templates\3rdClass\SwordMuse.xml). A 3rd-prof class's full skill set is the union of its lineage trees (base -> 1st -> 2nd -> 3rd); 3rdClass trees only contain getLevel 76-83 entries (incl. Forgotten-Scroll skills at 81-83). Tree rows list one row per (skillLevel, getLevel) - take the highest skillLevel. No tree row anywhere has skillLevel >= 100, so enchant levels are a non-issue in trees; all reported levels are base maxima.
- Templates: game\data\stats\players\templates\{StartingClass,1stClass,2ndClass,3rdClass}\*.xml; 3rdClass holds all 36 third-profession files (incl. all 21 combat classes above), each file starts with <classId>NN</classId> plus stats and creation points. Naming = PascalCase class name, apostrophes kept (Eva'sTemplar.xml, FemaleSoulHound.xml).
- Skill data: game\data\stats\skills\NNNNN-NNNNN.xml (68 range files, ~6100 skills). One flat element per skill: <skill id levels name> with shared child tags <operateType> (A1/A2/A3 = active, CA1 = channelled, DA1/DA2 = dash-attack actives (Kamael Rush family), T = toggle, P = passive), <targetType> (ONE, SELF, AREA, FRONT_AREA, AURA, PARTY, GROUND, SERVITOR, UNLOCKABLE, CORPSE_MOB...), <castRange>, <hitTime>, <reuseDelay>, <mpConsume>; per-level values live in <table name="#..."> rows (use last value for max level). castRange may itself reference a #castRange table - e.g. 28 Aggression -> 800, 494 Shoulder Charge -> 600 (both resolved above).
- "-" castRange = no castRange element in XML = self-centered (AURA AoE around caster) or self/ground-placed skill.
